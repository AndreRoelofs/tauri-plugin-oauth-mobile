## Default Permission

Allows the OAuth session plugin to open ASWebAuthenticationSession.

#### This default permission set includes the following:

- `allow-authenticate`

## Permission Table

<tr>
<th>Identifier</th>
<th>Description</th>
</tr>

<td>

`oauth-session:allow-authenticate`

</td>
<td>

</td>
</tr>

<tr>
