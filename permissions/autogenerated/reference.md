## Default Permission

Run OAuth 2.0 / OIDC authorization on mobile via AppAuth.

#### This default permission set includes the following:

- `allow-authenticate`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`appauth:allow-authenticate`

</td>
<td>

Enables the authenticate command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`appauth:deny-authenticate`

</td>
<td>

</td>
</tr>
</table>
